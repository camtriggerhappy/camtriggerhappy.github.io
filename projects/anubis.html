My Contributions

For AZRAEL I served as the Astrobotics team lead and was responsible for systems engineering and integration. I was additionally on the software team and responsible for much of the controls code.

Specifically, I was responsible for:

  • Configuring the networking to allow for low latency control and managing bandwidth utilization
  • Writing the low-level multithreaded drivetrain controller that calculated odometry and supplied commands to the differential drivetrain at 100Hz
  • Writing code that ran a custom trained YOLO model to identify key competition objects (Shown in SAR)
  • Training YOLO model on dataset that was partially synthetically generated. (Shown in SAR)
  • Wrote code to find the position of Fiducial Markers relative to the robot (Shown in SAR)
  • Wrote Sampler controller with MicroRos in order to control the sampler drilling platform, pumps, and servo cache (Shown in SAR)
  • Wrote GPS on an RP2040 driver to allow for sensor fusion between our GPS and IMU
  • Wrote code to utilize an EKF for fusing together IMU, GPS, and Drivetrain odometry data
Leadership
  • Focusing the sub-leads on reducing the number of actuators and highly unknown development items

Technologies

  • ROS2: all robotside code that is not on a microcontroller
  • Extended Kalman Filter: fused together IMU, GPS, and Odometry data for a better state estimate
  • Object Detection: Using YOLO we were able to identify a variety of objects required by the competition
  • CAN: Used to control all actuators on the robot except for those directly controlled by MCU(stepper, servo, pumps)
